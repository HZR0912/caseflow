# ADR-0013：以业务收据判分的版本化评测门禁

状态：已接受；日期：2026-10-25。

W11 需要证明改动没有破坏已有办事流程。采用固定的 60 业务场景和 60 内部对抗场景，每项独立运行五次。评测调用真实规划、审批、执行和补偿服务，以隔离 PostgreSQL 中的供应商状态、操作日志及引用原文判分。身份来自场景的可信角色字段。

发布必须同时通过完整性、绝对指标、逐例断言和可比基线检查。缺结果、重复结果、OPA 降级、配置不匹配均失败。首次基线只能显式 bootstrap，普通 CI 不生成或更新基线。规则模式不冒充 LLM 评测，已参与开发的数据不冒充盲测。

否决只检查最终回复、只看平均成功率、失败时自动更新基线：这些方式会漏掉实际副作用、偶发失败或把退化变成新标准。暂不加入没有人工校准标签的 LLM judge。

代价：五次规则执行不会证明模型随机稳定性；本地供应商适配器不覆盖 HTTP 网关；服务重建不能代替进程强杀测试。W7/W8 原有强杀验证与本评测互补。场景、制度或策略变化需要审查后显式重建基线。真实模型与人工标签到位后，建立独立 profile 和盲测基线，不能沿用本模式分数。
