## 写 ADR 的规矩

1. **必须写代价**：只写优点的 ADR 是宣传稿，不是决策记录。
2. **必须写被否掉的选项**：否则读者无法判断你是否真的做过选择。
3. **决定之后要有复核点**：如果前提变了（比如 Rego 规则长到读不懂），要能指出在哪里重新评估。
